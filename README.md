# Ludo Income — Render Ready + PWA

This package keeps the existing Ludo Income website/app flow and adds installable PWA support.

## PWA features
- Android Chrome install prompt when supported
- `manifest.json`
- Service worker (`/sw.js`)
- Ludo Income app icon (192x192 and 512x512)
- Standalone app mode after installation
- Website and installed app use the same frontend/backend and URL

## Deploy
Use Render with:
- Build: `npm install`
- Start: `npm start`

The existing backend/admin/My Match/room-code features are preserved.
